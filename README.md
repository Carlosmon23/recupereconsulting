# Recupere Consulting — Landing Page

Landing Page moderna e institucional para a **Recupere Consulting** (Revisão Tributária e Recuperação de Créditos de PIS/COFINS e Produtos Monofásicos).

Desenvolvido em **Next.js 14**, **Tailwind CSS**, **TypeScript** e **Lucide Icons**.

## 🚀 Funcionalidades

- **Design Exclusivo:** Paleta em azul profundo (*Navy & Electric Blue*) com inspiração em produtos modernos de tecnologia e finanças.
- **Simulador Interativo de Créditos:** Estimativa em tempo real de valores acumulados nos últimos 60 meses por segmento e faturamento mensal.
- **Integração WhatsApp:** Disparo de mensagens com o cálculo do simulador já preenchido diretamente para o consultor.
- **Seções Estruturadas:**
  - Nossas Soluções Especializadas
  - Segmentos Atendidos (com análise tributária por setor)
  - Passo a Passo do Processo em 5 Etapas
  - Tabela Comparativa (Recupere vs. Métodos Tradicionais)
  - Depoimentos Verificados e Casos de Sucesso
  - FAQ Interativo
  - Modal de Diagnóstico Rápido
  - Floating WhatsApp Action Button
  - Rodapé em Conformidade com a IN RFB nº 2.055/2021

## 🛠️ Tecnologias

- [Next.js 14 (App Router)](https://nextjs.org/)
- [React 18](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/)
- [TypeScript](https://www.typescriptlang.org/)

## 💻 Executar Localmente

```bash
# Instalar dependências
npm install

# Rodar servidor de desenvolvimento
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000) no seu navegador.

## 🚢 Deploy na Vercel

O projeto foi preparado para deploy automático na Vercel:
1. Conecte o repositório na [Vercel](https://vercel.com).
2. O framework é detectado como Next.js automaticamente.
3. Clique em **Deploy**.
